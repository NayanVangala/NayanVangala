### `$ about`

student developer who learns by building and breaking things. i spend most of my time on hardware/software hybrids — smart glasses, embedded systems, on-device ML — and hackathons. lately obsessed with accessibility tech and agents that automate the boring parts of building.

### `$ projects`

**[findr](https://github.com/NayanVangala/findr)**
ai memory assistant on meta ray-ban glasses. passive scene capture + semantic search + voice queries + caregiver alerts. built solo in 12 hours. won best solo hack @ marinhacks 2026.

**lexia**
real-time dyslexia reading assistant on glasses + raspberry pi. palm-gesture trigger, on-device ocr, offline tts. zero cloud dependency.
